## 🚀 HƯỚNG DẪN ĐƯA LÊN GITHUB & DEPLOY GITHUB PAGES TRONG 60 GIÂY

### Bước 1: Khởi tạo Git Repo trên máy và đẩy lên GitHub
Mở Terminal / PowerShell tại thư mục này và chạy các lệnh sau:

```bash
git init
git add .
git commit -m "feat: Launch Edge AI Camera Pitch & Product Landing Page by VU. Creative"
git branch -M main
git remote add origin https://github.com/<tai-khoan-github-cua-ban>/<ten-repository>.git
git push -u origin main
```

### Bước 2: Kích hoạt GitHub Pages miễn phí
1. Truy cập vào GitHub repository của bạn trên trình duyệt.
2. Bấm vào tab **Settings** (Cài đặt) &rarr; chọn mục **Pages** ở thanh menu bên trái.
3. Tại phần **Build and deployment**:
   - **Source**: Chọn `Deploy from a branch`.
   - **Branch**: Chọn nhánh `main` và thư mục `/ (root)`.
   - Bấm **Save**.
4. Chờ 30 - 60 giây, GitHub sẽ cung cấp đường link website của bạn:
   👉 `https://<tai-khoan-github-cua-ban>.github.io/<ten-repository>/`
