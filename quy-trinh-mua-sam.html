2. HƯỚNG DẪN CÀI ĐẶT MINI PC TRUNG TÂM (TẠI TP.HCM)
Bước 1: Cấu hình BIOS tự khởi động lại khi có điện (Quan trọng nhất)
  • Cắm bàn phím, màn hình vào Mini PC → Bật nguồn và bấm liên tục phím F2 / F10 / Delete để vào BIOS Setup.
  • Tìm đến mục Power Management → Tìm tùy chọn AC Recovery (hoặc Restore on AC Power Loss / State After Power Failure).
  • Chuyển giá trị sang: Power On (hoặc Turn On) → Bấm F10 để lưu và khởi động lại.
  • Tác dụng: Khi cúp điện rồi có điện trở lại, máy tự động bật lên mà không cần người bấm nút nguồn.
Bước 2: Cài đặt Hệ điều hành Ubuntu Server 24.04 LTS
  • Tải file ISO Ubuntu Server 24.04 LTS và dùng phần mềm Rufus ghi vào USB (tối thiểu 8GB).
  • Cắm USB vào Mini PC, chọn khởi động từ USB và cài đặt mặc định:
    • Đặt hostname: edge-ai-server | Username: admin.
    • Đánh dấu tích chọn: Install OpenSSH Server (để sau này ngồi từ xa điều khiển qua mạng).
Bước 3: Cài đặt Tailscale và Bật chế độ chấp nhận Subnet
# 1. Cài đặt Tailscale trên Ubuntu Server
curl -fsSL https://tailscale.com/install.sh | sh
# 2. Đăng nhập và kích hoạt nhận đường mạng từ các cục Pi ở quê
sudo tailscale up --accept-routes
3. HƯỚNG DẪN CẤU HÌNH 2 CỤC PI CẦU NỐI (LÀM TRƯỚC TẠI TP.HCM)
Bước 1: Flash hệ điều hành Armbian/DietPi lên Thẻ nhớ
  • Tải bản hệ điều hành nhẹ Armbian Linux (hoặc DietPi) tương ứng với dòng bo mạch Orange Pi Zero 3 hoặc TV Box.
  • Dùng phần mềm BalenaEtcher flash file image vào 2 thẻ nhớ 32GB → Cắm thẻ vào bo mạch → Cắm dây mạng vào modem nhà bạn ở TP.HCM để cài đặt lần đầu.
Bước 2: Bật tính năng IP Forwarding trên Linux
# Mở file sysctl.conf
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
Bước 3: Cài Tailscale và Biến Pi thành Subnet Router
# 1. Cài Tailscale
curl -fsSL https://tailscale.com/install.sh | sh

# 2. Chạy lệnh quảng bá dải mạng nội bộ (Ví dụ: Modem ở quê cấp dải 192.168.1.0/24)
sudo tailscale up --advertise-routes=192.168.1.0/24

# 3. Phê duyệt trên Web Tailscale (Admin Console):
# Vào https://login.tailscale.com/admin/machines
# Tìm chiếc Pi vừa kết nối -> Chọn Edit route settings -> Tích chọn ô "192.168.1.0/24" -> Bấm Save.

Lưu ý: Nếu modem nhà ở Đồng Tháp dùng dải 192.168.1.x, nhà Đồng Nai dùng dải 192.168.2.x, hãy chỉnh lệnh quảng bá route tương ứng để không bị trùng lặp IP giữa 2 nhà.

4. QUY TRÌNH BÀN GIAO & LẮP ĐẶT THỰC TẾ TẠI ĐỒNG THÁP & ĐỒNG NAI
Bước 1: Chuẩn bị Camera trước khi gửi (hoặc cài tại chỗ)
  • Cài app Ezviz hoặc Imou Life trên điện thoại. Kết nối camera vào Wi-Fi của nhà ở quê.
  • Vào mục Cài đặt Camera → Cài đặt mạng → Đặt IP tĩnh cho camera (ví dụ: 192.168.1.50 và 192.168.1.51).
  • Bật tính năng RTSP / ONVIF trong app và ghi nhớ Mật khẩu thiết bị (chính là mã Verification Code 6 chữ cái in dưới đáy camera).
Bước 2: Hướng dẫn người nhà ở quê cắm thiết bị (Chỉ 2 phút)
  • Đóng hộp gửi về quê gồm: Cục Pi + Củ sạc 5V + Dây cáp mạng LAN 1m.
  • Dặn người nhà ở quê thực hiện đúng 3 thao tác:
    1. Cắm củ sạc của cục Pi vào ổ điện 220V trong nhà.
    2. Lấy sợi dây mạng LAN: 1 đầu cắm vào cổng mạng của cục Pi, 1 đầu cắm vào cổng LAN (màu vàng) sau lưng modem Wi-Fi nhà mạng (Viettel/VNPT/FPT).
    3. Camera cứ cắm điện và bắt Wi-Fi như bình thường.
Bước 3: Ngồi tại TP.HCM thêm Camera vào Web Admin
  • Mở Web Admin của bạn trên máy tính: https://camera.nhaminh.com.
  • Vào mục "+ Thêm Camera Mới":
    • Chọn Nhà: Nhà Ba Mẹ (Đồng Tháp).
    • Nhập URL RTSP: rtsp://admin:MẬT_KHẨU@192.168.1.50:554/h264/ch1/main/av_stream.
    • Bấm "Kiểm tra & Kết nối" → Màn hình hiện ảnh chụp snapshot thành công. Tiến trình AI tự động kích hoạt nhận diện ngã ngay lập tức!
